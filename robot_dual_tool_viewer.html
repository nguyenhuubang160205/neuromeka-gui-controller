Đang tải mô hình 3D Tool Robot...
🤖 Tool Kép Robot (Dual End-Effector)
Mô hình 3D tiêu chuẩn GLB dành cho Robot Neuromeka Indy7.
🎯 Kết Cấu Hai Nhánh Tích Hợp

1. Nhánh Kẹp Mềm Song Song: Thẳng đứng vuông góc mặt bích (trục Z), vươn dài xuống dưới (Z = -200 mm), trang bị 2 ngón kẹp gắn đệm cao su NBR mềm có rãnh khía chống trầy xước.

2. Nhánh Giác Hút Chân Không: Rút ngắn gọn gàng (Z = -75 mm), khớp quẹo 90° hướng miệng hút ra phương ngang, trang bị ty nhún lò xo giảm chấn và giác hút silicon đa tầng Ø 52 mm.

📐 Thông Số Kỹ Thuật (CAD Specs)
Mặt bích Robot: ISO 9409-1-50-4-M6
Hành trình kẹp mềm: 28 mm (±14 mm)
Vật liệu đệm kẹp: Cao su NBR / Polyurethane
Đường kính giác hút: Ø 52 mm (Bellows 2.5)
Áp suất khí nén: 0.4 - 0.7 MPa
Định dạng file: GLB Binary PBR (Embedded)
🎮 Điều Khiển Góc Nhìn
📂 Kéo thả file .GLB vào đây hoặc nhấn để chọn file khác
Sử dụng chuột trái để xoay 360°, chuột phải để trượt (pan), con lăn để phóng to/thu nhỏ.
